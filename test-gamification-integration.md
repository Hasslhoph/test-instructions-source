# Интеграция Геймификации с корпоративным порталом

## Описание
Настройка интеграции модуля Геймификация с корпоративным порталом Битрикс24.

## Шаги
1. Установить модуль Геймификация
2. Перейти в Настройки модуля
3. Выбрать Корпоративный портал
4. Сохранить изменения

## Ожидаемый результат
Баллы и рейтинги отображаются на портале.
